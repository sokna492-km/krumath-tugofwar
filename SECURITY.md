# Security Policy

## Supported versions

Security fixes are applied on the default branch of this repository.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email the maintainer privately (see the GitHub profile for the repo owner), and include:

- A short description of the issue
- Steps to reproduce
- Impact (auth bypass, room takeover, XSS, etc.)

You should receive an acknowledgement when possible. Please allow time for a fix before any public disclosure.

## Please do not

- Commit secrets, `.env` files, or private keys in PRs
- Paste production credentials into issues or discussions
- Test exploits against production deployments you do not operate
